# HYPIR fusion v2 / F1 五 case 实测（2026-09-11）

离线残差置信融合。未跑扩散，未改 HYPIR，未覆盖 fusion_v1。LPIPS = Alex，最长边 1024。

复现锚点：本组 `fusion_A`（`M_struct`）均 PSNR **28.460407**，与 fusion_v1 逐位一致。

## 四组 mask 公式

`conf = 1 - percentile_norm(GaussianBlur(mean_c |H200−LQ|, σ=8), 1–99)`

| 组 | 公式 | 产物 method（方案 A / 底板 LQ） | 产物 method（方案 B / 底板 H50） |
|---|---|---|---|
| **A** | 原 fusion_v1：`M_final = M_struct` | `fusion_A` | `fusion_B` |
| **B** | `M_final = M_struct` | 与 A 同一公式、同一组 PNG，不重复写盘 | 同左 |
| **C** | `M_final = M_struct * conf` | `fusion_A_conf` | `fusion_B_conf` |
| **D** | `M_final = M_struct * conf^2` | `fusion_A_conf2` | `fusion_B_conf2` |

额外写出 gamma=0.5：`M_struct * conf^0.5`（`fusion_*_conf05`）。其余与 v1 相同：scene α、Y 通道、Cb/Cr 锁 LQ。

**没有超过 texture_selective 28.48。** 门槛是锚 +0.05 dB → 28.53。F1 最好的方案 A 是原 v1（28.46，−0.020）；加上 conf 之后方案 A 单调变差。方案 B + conf 相对 fusion_B 略升（28.26 → 28.37），仍低于锚 0.11 dB。

gamma 越大，方案 A 越接近 LQ：28.46 → 28.28 → 28.20 → 28.11。残差置信把「有用锐度」和「幻觉」一起关掉了。

鱼头 crop 上 mean conf=0.686、mean struct=0.520。置信图**确实**在鱼头内部变暗（`crops/case4_mid04_fish_masks.png`），但 plant α=0.08 已经把 H200 残差削掉，输出从「模糊粉团」再往 LQ 挪半步，看不出新的删除，也看不出真绿植。

水面 crop 上 mean conf=0.911。百分位归一化之后，水面假波纹的残差相对全图很小，**conf 几乎不打水面**。v1 变糊靠的是 bird α=0.12，不是 F1。

## 逐 case 视觉

### case4 密集绿植（鱼头）

`crops/case4_mid04_fish.png`：H200 仍是带眼睛的鱼头。A/C/D 都是模糊粉团，彼此几乎看不出差别。GT 是褐色荚果，没有被恢复。

不是「conf 把鱼头检测并删除」。发生的是：置信图在鱼头内部降低，但生成强度本来就只有 0.08，再乘 conf 只是更接近 LQ。没有恢复真实叶片/荚果纹理。

`crops/case4_high02_leaf.png`：H200 的锯齿单叶在所有 fusion 里都被压回 LQ 的糊斑；GT 黄花枝条没有出现。

### case3 水面

`crops/case3_low02_water.png`：H200 有假波纹；A/C/D 都接近 LQ。C/D 比 A 更糊一点（crop PSNR 46.08 → 46.19 → 46.28，朝 LQ 46.64）。conf 图是亮的，F1 不是水面的主因。

### case1 文字 / case5 钟表

`comparison/case1.png`、`comparison/case5.png`：没有新的改字或改指针。C/D 比 A 更软，指标也说明锐度被 conf 杀掉（case1 32.17→32.06；case5 27.12→26.42）。结构保持，但 F1 在这两张上是净损失。

### case2 书脊

方案 A 从 29.20 掉到 28.60 / 28.40，是平均 PSNR 下滑的主要来源之一。大残差包含「清晰书脊字」，conf 把它当不可信。

## 机制判断

| 有效 | 无效 |
|---|---|
| 置信图能在鱼头内部变暗（Sobel 做不到的平滑区） | 大残差 ≠ 幻觉：文字、钟表、书脊同样残差大 |
| 方案 B + conf 相对 fusion_B 有 +0.11 dB | 任何 F1 变体都没有过 28.48 |
| 方案 A + conf 更接近 LQ，鱼头/水面更糊 | 没有恢复真实绿植；水面本来就不是大残差问题 |

当前做的仍是 **生成幅度控制**，不是语义错误检测。`M_struct * conf` 不能把「H200 补细节」和「H200 写错中频」切开。

## 结论

F1 **没有超过** `texture_selective` 28.48 PSNR，也没有在 case4 上恢复真实绿植，不能换锚。不要据此开 LoRA / Adapter / 100 张。

**当前瓶颈不是结构 mask，而是 H200 输出本身与 LQ 信息差异过大，需要进一步降低生成强度。**

更具体一点：

1. 输出空间再叠一层残差置信，只会把 v1 已经偏保守的结果进一步推向 LQ。
2. 继续降 H200 权重（更大 gamma、更小 α）打不平 28.48，只会更像 LQ。
3. 鱼头/错叶是 H200 的确定性中频映射，不是 mask 漏检能补上的细节。

不训练、不重跑 HYPIR、不加分类器。fusion_v1 产物未改。
